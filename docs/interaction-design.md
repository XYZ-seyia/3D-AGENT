# 编辑器交互设计

## 核心原则：编辑器里永远是面板级

编辑器中不存在"宏"的运行时概念。从模板启动时，先编译为面板再加载到画布。所有操作都直接作用于面板。

---

## 选择层级：Figma 式双层选择

- **单击** → 选中整个组件（一组已吸附的面板）→ 右侧显示整体参数（合并后的宽度、深度、高度）
- **双击** → 进入组件内部 → 选中单块板 → 右侧显示板级参数（尺寸、位置、接合方式）
- **点击空白** → 退出组件内部 → 回到整体层级

---

## 自动成组机制

当两块面板自动吸附并生成卡槽时：

- 它们自动成为一个"组"
- 右侧参数面板切换到整体视角
- 系统自动识别"值相同的维度"并合并为整体参数
- 例如：front.w = back.w = top.w = bottom.w = 200 → 合并显示为"整体宽度: 200"

每吸附一块新板，参数面板实时更新。用户在编辑过程中就能看到"整体"正在形成。

---

## 参数合并规则

- 数值相同的同类维度（如多块板的宽度）自动建议合并
- 可识别比例关系（如 shelf.pose.y = front.h × 50% → 绑定为比例参数）
- 厚度通常全部合并为"板厚"
- 来自同一 macro 模板的面板，合并时可参考来源线索（source_macro / source_role）

---

## 单板修改与 Override

当用户双击进入组件，修改了某块板的参数：

- 修改记录为 override
- 退出回到整体层级，该参数显示"已自定义"标记
- 想恢复统一，点重置即可
- **不存在"脱离 macro"的硬边界** — 组件始终是组件，只是有些参数被个别板覆盖

示例：

```
整体宽度：200mm          ← 统一，改了四块板一起动
整体高度：100mm (已自定义) ← front 被单独改成了 90mm，其余三块仍是 100
板厚：    3mm             ← 统一
```

---

## 发布流程

从编辑器发布为生成器时：

1. 点击"发布" → 进入预览弹窗
2. 系统自动识别可合并参数（基于值相同聚类 + 来源 macro 线索）
3. 用户在弹窗中：
   - 勾选/取消合并建议
   - 拖动滑块实时预览 3D 效果
   - 修改参数标签和范围
   - 展开查看具体绑定了哪些面板
4. 确认后发布

发布产物结构：

```json
{
  "template": {
    "panels": ["front", "back", "left", "right", "top", "bottom", "shelf"],
    "connections": [...]
  },
  "bindings": {
    "width":  ["front.w", "back.w", "top.w", "bottom.w"],
    "depth":  ["left.w", "right.w", "top.h", "bottom.h"],
    "height": ["front.h", "back.h", "left.h", "right.h"],
    "thickness": ["*.thickness"],
    "shelf_height": ["shelf.pose.y"]
  },
  "exposed_params": {
    "width":  { "label": "宽度", "min": 50, "max": 500, "default": 200 },
    "depth":  { "label": "深度", "min": 50, "max": 300, "default": 150 },
    "shelf_height": { "label": "隔板高度", "min": 20, "max": 280, "default": 75 }
  }
}
```

---

## 三种入口的统一模型

```
生成器视图：  macro params → compileMacro() → render         （快速、确定）
编辑器视图：  macro params → compileMacro() → panels → 用户编辑
发布时：      panels → 自动识别绑定 → 用户确认 → 生成器配置
```

---

## 编辑粒度总结

| 问题 | 答案 |
|------|------|
| 编辑器操作的是什么？ | 永远是面板 |
| 宏参数怎么改？ | 单击组件，在整体层级改 |
| 单板怎么改？ | 双击进入组件内部 |
| 脱离 macro 的边界？ | 不存在硬边界，override 标记"已自定义" |
| 发布为生成器时？ | 自动合并建议 + 用户确认 + 实时预览 |
